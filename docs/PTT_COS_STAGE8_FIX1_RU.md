# Stage 8 Fix 1 — полярность PTT и безопасное завершение

## Новая настройка

В секции `[Transmit]` добавлен параметр:

```ini
PttActiveLevel = High
```

Допустимые значения: `High` и `Low`. Это уровень GPIO3, который включает передачу. Неактивный уровень автоматически выбирается противоположным. В ручном тесте именно этой платы CM108 было подтверждено: `High` включает TX, `Low` отпускает PTT, поэтому начальное значение — `High`. Если конкретный интерфейс инвертирует вход PTT, можно указать `Low`.

`CosActiveHigh` — отдельный параметр: он задаёт, какой уровень VOLDN считается занятым радиоканалом. Он не связан с полярностью GPIO3.

## Почему PTT мог включаться сразу после ответа

При `VoxEnabled = false` каждый входящий RTP-кадр считается активностью, в том числе кадры цифровой тишины. RTP обычно продолжает идти и при молчании абонента, поэтому после установления медиасессии PTT может включиться сразу. Чтобы включать передачу только при голосе, используйте:

```ini
VoxEnabled = true
```

и настройте `[VOX] ThresholdDbfs`, `ActivationDelayMs` и `ReleaseDelayMs`.

## Безопасное завершение

- `Ctrl+C`: синхронно отправляется неактивный уровень GPIO3 до асинхронного останова сервисов.
- `SIGTERM` (например, остановка systemd): используется тот же путь.
- При остановке приложения контроллер повторно отправляет неактивный уровень несколько раз на открытом HID-дескрипторе, ожидает завершения HID-потоков и повторяет сброс непосредственно перед закрытием `/dev/hidrawN`.
- При ошибке HID выполняются повторные попытки установить неактивный уровень, а повторные запросы передачи блокируются.
- COS используется как блокировка начала передачи. Если COS становится активным уже во время собственной передачи, текущий PTT не сбрасывается (радиостанция может видеть собственный RF через COS); после отпускания PTT занятый канал блокирует следующую передачу.

## Проверка после обновления

Сначала проверять с физически отсоединённым PTT-проводом радиостанции. Убедиться, что стартовый лог показывает `активный уровень PTT=HIGH` (или выбранный уровень) и что безопасный уровень противоположен ему. Во время теста наблюдать `COS: VOLDN raw=0x..` и проверять правильность `CosActiveHigh`.

Передача через PTT при `VoxEnabled=false` ожидается на любых RTP-кадрах, включая тишину. Если нужен режим «передавать только когда собеседник говорит», включить VOX.

**Важно:** ни `Ctrl+C`, ни программная логика не гарантируют отпускание PTT при физическом отключении USB, зависании контроллера или потере питания. Внешний аппаратный вход PTT должен иметь безопасную подтяжку/схему, которая по умолчанию отпускает передачу.
