# Конфигурация RadioSipGateway Linux

Конфигурация читается из INI-файла. Пример: `config/radiogateway.example.ini`.

## Секции

- `[SIP]`: адрес/порт сервера, имя и пароль, локальный порт, интервал повторной регистрации и запрашиваемый срок регистрации (`RegistrationExpirySeconds`).
- `[Audio]`: имена ALSA capture/playback устройств, частота дискретизации, удержание устройств открытыми.
- `[Transmit]`: режим `cm108`, `vox` или `none`; опциональное `PttEnabled`; путь HID; назначение GPIO3/VOLDN COS; полярность COS; задержка отпускания PTT.
- `[VOX]`: порог, время подтверждения открытия и задержка закрытия.
- `[Radio]`: ограничения TOT, уровни и включение служебных сигналов, DTMF, позывной и WAV.
- `[Logging]`: желаемый уровень журналирования.

Пилот-тон намеренно отсутствует: параметров генерации или мультиплексирования пилота в конфиге Linux-версии быть не должно.

Пароль хранится в файле конфигурации, поэтому файл должен быть доступен только root и группе службы. Не храните рабочий конфиг в Git.

## Режимы PTT

- `Mode = cm108`: GPIO3 CM108 управляет PTT; HIGH включает передачу, LOW выключает.
- `Mode = vox`: зарезервирован для программного PTT без аппаратного GPIO (ещё не реализован).
- `Mode = none`: безопасный режим без управления передачей.

Для Stage 8 требуется явный `PttEnabled = true`, `HidrawPath = /dev/hidraw0`, `PttPin = gpio3`, `CosSource = voldn`. По умолчанию `PttEnabled = false`. COS читается из бита `0x02` первого байта входного HID-отчёта; до первого отчёта COS считается неизвестным и PTT блокируется. `VoxEnabled = true` включает RMS-порог на входящем SIP-аудио перед запросом PTT; при выключенном VOX любой входящий RTP аудиокадр считается активностью.

Эти функции экспериментальные и проверены только поэтапно на конкретной плате CM108 `0d8c:000c`.
