# Конфигурация RadioSipGateway Linux

Конфигурация читается из INI-файла. Пример: `config/radiogateway.example.ini`.

## Секции

- `[SIP]`: адрес/порт сервера, имя и пароль, локальный порт, интервал повторной регистрации и запрашиваемый срок регистрации (`RegistrationExpirySeconds`).
- `[Audio]`: имена ALSA capture/playback устройств, частота дискретизации, удержание устройств открытыми.
- `[Transmit]`: режим `cm108`, `vox` или `none`; переключатель VOX; путь HID; задержка отпускания PTT.
- `[VOX]`: порог, время подтверждения открытия и задержка закрытия.
- `[Radio]`: ограничения TOT, уровни и включение служебных сигналов, DTMF, позывной и WAV.
- `[Logging]`: желаемый уровень журналирования.

Пилот-тон намеренно отсутствует: параметров генерации или мультиплексирования пилота в конфиге Linux-версии быть не должно.

Пароль хранится в файле конфигурации, поэтому файл должен быть доступен только root и группе службы. Не храните рабочий конфиг в Git.

## Режимы PTT

- `Mode = cm108`: планируемый основной режим — аппаратное переключение через CM108 GPIO/HID.
- `Mode = vox`: программное управление передачей по уровню аудио для обратной совместимости.
- `Mode = none`: безопасный диагностический режим без управления передачей.

`VoxEnabled` предусмотрен как независимый переключатель совместимости, но окончательная логика сочетания VOX и аппаратного PTT будет реализована так, чтобы несколько компонентов не конкурировали за состояние PTT. До реализации runtime значения служат только конфигурационной схемой.
